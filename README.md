## 📌 About

**DevMatrix Dashboard** is a custom Rainmeter skin designed to provide a clean and lightweight desktop interface focused on development tools and basic system monitoring.

The project was created as a practical development exercise, combining desktop customization, Rainmeter skin development, Windows system monitoring, configuration management, Git/GitHub, project organization, and UI/UX principles.

The interface follows a minimal **developer / terminal-inspired aesthetic**, using a dark interface, green accent color, and the **Moosha Corp** visual identity.

---

## ✨ Features

### 🕒 Clock

Displays the current time and date using the local Windows system time.

### 💻 System Monitoring

The `SYSTEM` section provides basic real-time monitoring of:

- CPU usage
- RAM usage

Visual progress bars provide a quick overview of system resource usage.

### 💾 Disk Monitoring

The dashboard monitors:

- `C:` drive
- `D:` drive

Each drive displays storage information together with a visual usage bar.

### 🚀 Development Shortcuts

Quick access to frequently used applications:

- OBS Studio
- Ubuntu / WSL
- Visual Studio Code
- pgAdmin 4
- Postman
- Windows Calculator

Application paths are configurable through `Variables.inc`.

### ⚡ Floating Quick Launcher

A separate floating launcher designed for quick access to frequently used development applications.

Currently includes:

- Visual Studio Code
- Postman
- OBS Studio
- Windows Calculator

The Quick Launcher features a compact interface, local PNG icons, a dark background, green accents, and draggable positioning.

It can be opened through Rainmeter or from the `FAST MENU` button integrated into the main dashboard.

### 🎨 Visual Identity

The interface uses the **Moosha Corp** logo as part of the project's visual identity.

The design is based on:

- Dark background
- Green accent color
- Consolas typography
- Minimal borders
- Compact spacing
- Terminal-inspired aesthetics

# 🚀 Installation

## Requirements

- Windows 10 or Windows 11
- Rainmeter

Download Rainmeter from:

https://www.rainmeter.net/

## Installation

### Option 1 — Download from GitHub

Download the repository as a ZIP file and extract it.

Copy the `DevMatrixDashboard` folder to:

```text
Documents\Rainmeter\Skins\
```

The final structure should look like:

```text
Documents
└── Rainmeter
    └── Skins
        └── DevMatrixDashboard
            ├── @Resources
            ├── DevMatrix.ini
            └── ...
```

Open Rainmeter and load `DevMatrix.ini`.

### Option 2 — Clone with Git

```bash
git clone https://github.com/fernandopereira-tech/devmatrix-dashboard.git
```

Then place the repository inside:

```text
Documents\Rainmeter\Skins\
```

# ⚙️ Configuration

Application paths are stored in:

```text
@Resources/Variables.inc
```

Example:

```ini
; OBS Studio
OBSPath=D:\Program Files\obs-studio\bin\64bit\obs64.exe

; Postman
PostmanPath=%LOCALAPPDATA%\Postman\Postman.exe

; Ubuntu / WSL
UbuntuAppID=Microsoft.AutoGenerated.{63DCD66C-22BE-CEF0-C242-1A8C60B6C300}

; Visual Studio Code
VSCodePath=%LOCALAPPDATA%\Programs\Microsoft VS Code\Code.exe

; pgAdmin 4
PgAdminPath=%LOCALAPPDATA%\Programs\pgAdmin 4\runtime\pgAdmin4.exe

; Calculator
CalculatorPath=calc.exe
```

Application paths can differ depending on the Windows installation. If a shortcut does not work, adjust its path in `Variables.inc`.

# 🎨 Customization

Visual settings can be adjusted through:

```text
@Resources/Variables.inc
```

For example:

```ini
FontFace=Consolas
FontColor=235,235,235,255
AccentColor=0,255,102,255
MutedColor=130,130,130,255
```

Panel settings are also centralized there:

```ini
PanelWidth=340
PanelHeight=700
PanelBackground=15,18,17,155
PanelBorder=0,255,102,65
```

Text styles are maintained separately in:

```text
@Resources/Styles.inc
```

This separation makes the project easier to maintain and customize.

# 🔐 Security & Privacy

DevMatrix is designed to operate locally on the user's Windows system.

The project currently:

- Does not require API keys
- Does not store passwords
- Does not store authentication tokens
- Does not require user accounts
- Does not collect personal data
- Does not require cloud services for its core functionality

The skin accesses local Windows resources and launches applications configured by the user.

> **Note:** Application paths inside `Variables.inc` are local configuration values and should be adapted to the user's own Windows installation.
